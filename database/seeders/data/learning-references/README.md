# Alibaton Internal Performance & Development Reference Library V1

This folder is the controlled internal project-reference package used by the Performance & Development system.

It now supports both:
- Learning / Training source-reference governance; and
- Competency Framework / Role Profile / Assessment governance.

## Use in Learning
- Link each published Learning course/version to one or more appropriate document IDs.
- Display source title, document ID, version, and effective date where source traceability is required.
- If a client-issued official document is received later, create a new source/document version and review affected course versions.
- Do not rewrite historical completed-course evidence when a source changes; create a new course version when the change is material.

## Use in Competency
- Use ALB-PND-GDL-014 as the governance basis for Competency Library, Role Profiles, assessments, validated gaps, development, and reassessment.
- Use ALB-PND-REF-015 and `ALIBATON_COMPETENCY_REFERENCE_BASELINE_V1.json` as the documented current project baseline for the finalized Competency Framework v1.
- Role Profiles are reusable organizational standards, not per-employee records.
- Active Role Profiles should resolve from canonical position + department/context where applicable.
- Official current proficiency comes from finalized validated competency assessments, not from course completion or manually edited current-level fields.
- Material requirement changes should create a new governed profile/version rather than rewrite historical assessment context.

## Important source limitation
The Competency governance and requirement matrix added on 2026-09-11 are **project-controlled interim references** because the project team did not receive a complete official client-issued competency framework, role matrix, or job-description set.

They must not be represented as official Alibaton policy. If Alibaton later supplies official controlled sources, those sources supersede the interim baseline and affected system records must be reviewed/versioned.
